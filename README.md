# Projeto_Etd
Pipeline ETL modular desenvolvido para a cadeira de Extração e Transformação de Dados. Extração de indicadores do Banco Mundial.

## Domínio Escolhido
Escolhemos o domínio de **Economia Global e Desenvolvimento**, utilizando dados do Banco Mundial. 
A análise foca-se na relação entre indicadores macroeconómicos (PIB, Inflação) e indicadores sociais.

## Preparação do Setup
Preparar os Dados de Volume (Bulk)
Devido ao tamanho, os dados brutos não estão no GitHub.
1. **Download:** Descarregar o ficheiro ZIP "CSV File" do **World Development Indicators (WDI)** através deste link oficial:
   [World Bank Data Catalog - WDI](https://datacatalog.worldbank.org/search/dataset/0037712/World-Development-Indicators)
2. **Extração:** Extrair o conteúdo para a pasta `data/raw/bulk/`.
